# chatbot — чаты сайтов недвижимости в Telegram

Робот держит открытым Chrome, где ты залогинен на сайтах, пересылает новые сообщения из чатов в Telegram-бота, а ответы из бота отправляет обратно в чат на сайте. Сначала делаем ЦИАН, потом остальные сайты, Авито последним.

## Установка (и на ноутбуке, и на компьютере в России)

1. `git clone` (или `git pull`, если уже склонировано).
2. Запусти `install.bat`. Он найдёт рабочий Python, создаст папку `.venv` и поставит туда пакеты. Глобальный Python не трогает.
3. Впиши в `config.json` токен бота, `api_id` и `api_hash` (берутся на https://my.telegram.org → API development tools). Этот файл в git не попадает.
4. На компьютере в России в `config.json` должно быть `"use_proxy": true`. Тогда бот ходит в Telegram через tg-ws-proxy, а секрет прокси берёт сам из `%APPDATA%\TgWsProxy\config.json`. На ноутбуке в Грузии ставь `false`.

## Скрипты

| Файл | Что делает |
|---|---|
| `install.bat` | ставит всё нужное в `.venv` |
| `recon_cian.bat` | разведчик: открывает Chrome, ты входишь в ЦИАН и открываешь сообщения, скрипт записывает, что сайт загружает (`recon_cian/`) |
| `bot_test.bat` | проверка бота: отвечает «Работаю» и показывает твой chat_id |

## Что не попадает в git

`config.json` (токены), `profile_*/` (вход на сайты), `recon_*/` (переписка с людьми), `*.session` (сессия Telegram), `.venv/`.
